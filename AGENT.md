# Task Approval Workflow

When given a task, before doing any work:

1. Restate the task as a short **Goal**: one or two sentences describing what
   will be done, based only on what was asked.
2. Ask for approval: "Does this look right? Approve to start, or tell me what
   to change."
3. Wait for an explicit approval before creating or editing any file, or
   running any command.

If the user changes the request, update the Goal and ask again before
proceeding.
